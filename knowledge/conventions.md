# Roblox Conventions

## Purpose

Use this module to keep the project consistent.

## Conventions

- Use clear, descriptive names.
- Keep one responsibility per module.
- Use consistent folder and service patterns.
- Put shared definitions in shared locations only when they are safe to expose.
- Keep temporary code separate from production code.

## Procedure

1. Check existing project patterns.
2. Match the established style unless there is a strong reason to improve it.
3. Apply the same naming pattern across similar systems.
4. Keep new files aligned with the current tree.
5. Document any deliberate deviation.

## Rules

- Consistency beats cleverness.
- Similar systems should look similar.
- Do not invent a new pattern for every feature.

## Review checklist

- The names are clear.
- The structure matches the rest of the project.
- The pattern is reusable.
- New work does not feel isolated from the codebase.
