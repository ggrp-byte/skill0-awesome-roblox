# Roblox Animation

## Purpose

Use this module for character motion and animation-driven gameplay.

## Procedure

1. Identify the rig type and animation purpose.
2. Keep animations readable at gameplay speed.
3. Separate locomotion, combat, emotes, and cinematic motion.
4. Test transitions and blending.
5. Confirm animation playback works in the intended network setup.

## Rules

- Use animation to clarify action, not hide it.
- Keep important gameplay motions easy to read.
- Avoid unnecessary animation complexity when a simpler motion works.
- Match animation timing to the game’s pace.

## Review checklist

- Animations match the rig.
- Transitions are smooth.
- Timing feels correct in playtest.
- The motion helps gameplay readability.
