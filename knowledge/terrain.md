# Roblox Terrain

## Purpose

Use this module for natural environments and terrain-driven worlds.

## Procedure

1. Define the biome or terrain role.
2. Block out the landform shapes first.
3. Add depth, variation, and traversal only after the large forms work.
4. Keep player navigation readable.
5. Check performance as the terrain grows.

## Rules

- Prefer the minimum terrain complexity needed for gameplay.
- Make traversal routes obvious.
- Avoid visual noise that blocks navigation.
- Use terrain detail to support gameplay, not distract from it.

## Review checklist

- The terrain supports the map flow.
- The silhouette reads clearly.
- The terrain does not overload the scene unnecessarily.
