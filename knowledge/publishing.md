# Roblox Publishing

## Purpose

Use this module when a build is ready to ship.

## Procedure

1. Confirm the feature set is complete.
2. Run the security checklist.
3. Run the performance checklist.
4. Confirm the UI checklist.
5. Confirm the multiplayer checklist if the game uses networking.
6. Prepare the release notes and thumbnail text.
7. Release the update only after the checks pass.

## Rules

- Do not publish a build that has known abuse paths.
- Do not publish a build without basic playtest coverage.
- Do not rely on last-minute manual fixes to hide structural problems.

## Review checklist

- The build is stable.
- The release notes are accurate.
- The important systems were tested.
- The release plan is simple and reversible.
