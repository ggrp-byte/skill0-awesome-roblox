# Roblox Game Design

## Purpose

Use this module for the structure of the game itself.

## Procedure

1. Define the core loop.
2. Define the secondary loop.
3. Define the reward cadence.
4. Define the onboarding path.
5. Define the reason players return.

## Rules

- The loop must be understandable in a few seconds.
- Progression should feel earned.
- The player should know what to do next.
- Add complexity only after the base loop is enjoyable.

## Review checklist

- The game has a clear hook.
- The core loop is repeatable.
- New players understand the goal.
- The pacing supports the intended session length.
