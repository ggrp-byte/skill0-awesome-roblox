# skill0-awesome-roblox

Modular Roblox skill repository for Codex.

## Structure

- `skill.md` routes tasks to the right module.
- `knowledge/` contains domain knowledge.
- `workflows/` contains step-by-step procedures.
- `checklists/` contains validation gates.
- `examples/` contains reference game patterns.
- `templates/` contains reusable file structures.
- `scripts/` contains optional helper resources.
