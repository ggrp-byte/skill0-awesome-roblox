# Optimize Roblox Game Workflow

## Goal

Improve performance without breaking behavior.

## Procedure

1. Measure the bottleneck.
2. Identify the hot path.
3. Remove unnecessary work.
4. Apply the smallest fix that matters.
5. Measure again.
6. Confirm the user experience still feels correct.

## Rules

- Do not optimize blind.
- Prefer removing cost over micro-optimizing code.
- Keep gameplay readable after the change.

## Output expectation

Describe the bottleneck, the fix, the measurement, and the result.
