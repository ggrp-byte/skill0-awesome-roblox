# Create Roblox Game Workflow

## Goal

Turn an idea into a playable Roblox project.

## Procedure

1. Define the game loop.
2. Choose the core systems that support that loop.
3. Build the project structure.
4. Implement the minimum playable version.
5. Test the loop before adding content.
6. Expand only after the core loop works.

## Rules

- Start with the smallest viable version.
- Build the foundation before cosmetics.
- Keep each system isolated and testable.
- Use the security and testing checklists before calling the game done.

## Output expectation

Summarize the loop, the systems created, the remaining risks, and the next implementation step.
