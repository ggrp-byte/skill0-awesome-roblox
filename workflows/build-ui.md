# Build Roblox UI Workflow

## Goal

Create UI that is clear, responsive, and easy to use.

## Procedure

1. Define the player task.
2. Sketch the information hierarchy.
3. Build reusable UI pieces.
4. Wire input and state carefully.
5. Test at multiple resolutions and input types.
6. Refine spacing, contrast, and feedback.

## Rules

- Start with usability, not effects.
- Keep the interface readable.
- Separate UI presentation from gameplay logic.

## Output expectation

Describe the task, the layout, the interaction model, and the test result.
