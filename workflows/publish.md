# Publish Roblox Experience Workflow

## Goal

Release a build with a clear checklist and low risk.

## Procedure

1. Confirm the feature is complete.
2. Run the security checklist.
3. Run the testing checklist.
4. Run the performance checklist.
5. Confirm the UI and multiplayer checklists if relevant.
6. Prepare release notes and rollout details.
7. Publish only after the checks pass.

## Rules

- Do not ship known abuse paths.
- Do not skip the final validation pass.
- Keep the rollout simple and reversible when possible.

## Output expectation

State readiness, remaining risks, and the release plan.
